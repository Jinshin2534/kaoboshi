# かおぼし

カメラで夜空を映しておくと、ときどき流れ星が流れ、何回かに1回は誰かの顔が流れ星になって横切るWebページです。

- 画面には何も出ず、カメラ映像だけが全画面で映ります（スマホは背面カメラ）
- 初回だけ「顔画像を選ぶ」ボタンが出ます。写真から顔を自動で見つけて丸く切り抜きます（MediaPipe Face Detector。見つからないときは中央を切り抜き）
- 切り抜いた顔はその端末のブラウザ（IndexedDB）にだけ保存され、どこにも送信されません
- **画面を長押し（Mac は S キー）** で隠し設定が開き、顔の追加・削除、頻度の調整、「いま流す」ができます
- 普通の流れ星が4回続いたら次は必ず顔が流れます。同じ顔は2回続けて流れません

## 開発

```bash
pnpm install
pnpm dev     # http://localhost:6010 （--host 付きなので同じLANのスマホからも開けますが、カメラはHTTPSが必要）
pnpm test    # 純粋ロジック(src/lib)のテスト
pnpm build
```

## 構成

- `src/lib/` 純粋関数（テスト済み）: `crop.js` 切り抜き範囲、`meteor.js` 軌道とフェード、`schedule.js` 間隔・顔か普通の星かの選択
- `src/face.js` 顔検出と切り抜き、`src/render.js` 描画、`src/store.js` 保存、`src/main.js` 配線
- `window.__app` からヘッドレス検証用に `launch('face')` などを呼べます
